# ftool-parser-python

Parser em Python para arquivos `.ftl` do FTool 4.00/4.01.

Nesta versão, o projeto lê materiais, seções, cargas nodais, cotas, barras,
nós derivados e apoios, normalizando as grandezas para SI (`N`, `m`, `Pa`).
O notebook contém testes de regressão e validação visual dos modelos de ponte.
